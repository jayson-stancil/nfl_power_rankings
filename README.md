# NFL Power Rankings

Independent weekly Glicko-2 power-ranking pipeline for all 32 NFL teams,
seeded by a preseason media-consensus (Borda count) prior.

This repo has no app of its own. It exists so the three fantasy-league
power-rankings apps (`adg_dynasty_league_power_rankings`,
`sleeper-power-rankings`, `corbin_dynasty_league_power_rankings`) can each
show an "NFL Power Rankings" tab without duplicating this computation three
times -- they read the CSVs below straight off
`raw.githubusercontent.com`, the same way each already reads its own
league data.

## Data (`data/`)

- `current.csv` -- latest week's full standings table: one row per team
  (Rank, Team, ABBREV, Rating, Deviation, Volatility, Record, RankChange,
  RatingChange, PreseasonRank), plus the Week/WeekLabel it's current
  through.
- `history.csv` -- long format rating history (Week, WeekLabel, Team,
  ABBREV, Rating), one row per team per week since Week 2. Week 1 (pure
  preseason prior, no games played) is intentionally excluded. This is
  what the apps' "Rating Trajectory" view plots.
- `teams.csv` -- ABBREV -> full team name + ESPN logo URL, refreshed every
  run from `nflreadr::load_teams()`. Kept separate from `current.csv` so
  the Shiny apps don't need nflreadr just to render a logo.
- `meta.csv` -- season, latest_week, week_label, run_date.
- `preseason.csv` -- static input: the preseason Borda consensus (team,
  outlet-by-outlet ranks, BordaScore, BordaRank) that seeds every team's
  Week 1 Glicko-2 rating. Not regenerated by the pipeline -- edit this file
  by hand each season before Week 1.

## Pipeline (`R/nfl_power_rankings.R`)

Pulls the season schedule from `nflreadr::load_schedules()`, runs
`PlayerRatings::glicko2()` week by week from the preseason prior, and
writes the four CSVs above. Every run recomputes the full season from
scratch (Glicko-2 is deterministic given the same games), so a re-run or a
late score correction is always safe.

Runs weekly via `.github/workflows/weekly.yml` (Tuesdays 11:00 UTC, same
cadence as the three league repos) or on demand via "Run workflow" in the
Actions tab. Can also be run locally: `Rscript R/nfl_power_rankings.R`
(optionally pass a week number to cap how far it computes, e.g.
`Rscript R/nfl_power_rankings.R 3`).
